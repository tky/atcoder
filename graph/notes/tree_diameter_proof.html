なぜ「適当な頂点からの最遠点」は
必ず直径の端点なのか

典型90-003 / 木の直径の2回走査が正しい理由。道具は ABC126 D と同じ「合流点での分解」だけ。

0. 何が心配だったのか

①で頂点1から最遠点 u を探し、②で u からの最遠距離を直径として採用する。この手順が壊れるとしたら、①が「葉だけど、どの最遠ペアにも入らない頂点」を掴んでしまう場合だった。

もし①が 6 を掴んだら、②が返す最遠距離は dist(6,1) = dist(6,5) = 3 — 本当の直径 4 より小さい誤答になる。だから「①は 6 のような頂点を絶対に掴まない」を証明したい。

手描きメモの直感は「6 が最遠になるには枝 3–6 が長くないといけない。でも長くした瞬間、その枝ごと直径に昇格する」だった。以下はこの直感をそのまま不等式にしたもの。

1. 登場人物と、使っていい事実

a–b: 最遠ペア(直径)。長さ D = dist(a,b)
s: 走査①の出発点(どこでもよい)
u: s からの最遠点(①が掴む頂点)
m: s から直径経路 a–b への合流点 — s から a へ行くにも b へ行くにも、必ず m を通ってから直径の上を走る(木の経路は一意だから)

使っていい事実は2つだけ。

1u は s から最遠: dist(s,u) ≥ dist(s,x) が全頂点 x で成り立つ。特に x = a, b。
2D は全ペアの最大: dist(x,y) ≤ D が全ペアで成り立つ。

ゴールは dist(u,b) ≥ D を示すこと。事実2と合わせれば dist(u,b) = D、つまり「u は b を相方とする最遠ペアの端点」になる。

s→u の経路が直径経路に触れるかどうかで、形は2つしかない。

2. Case 1: s→u の経路が直径に触れる場合

経路は m で直径に乗り、しばらく直径上を(ここでは a の方向へ)走り、ある点 c で直径を離れて u へ向かう(c = m のこともある)。

s→u と s→a を、通る線分の色で書き下ろす。

dist(s,u) = dist(s,m) + dist(m,c) + dist(c,u)
dist(s,a) = dist(s,m) + dist(m,c) + dist(c,a)

1「u は最遠」より dist(s,u) ≥ dist(s,a)。両辺の共通部分(緑と橙)が消える:

dist(s,m) + dist(m,c) + dist(c,u) ≥ dist(s,m) + dist(m,c) + dist(c,a)
∴ dist(c,u) ≥ dist(c,a) … (★)

(★)が手描きの直感そのもの: u への枝(赤)は、直径の a 側の残り(青)と同じ以上に長い。枝が「直径に昇格できる長さ」になっている。

では u から b までの距離を測る。u→b は赤を戻って c、そこから直径を b まで走るしかない(経路の一意性)。直径 D も c で2つに割れることに注意:

dist(u,b) = dist(c,u) + dist(c,m) + dist(m,b)
D = dist(a,b) = dist(c,a) + dist(c,m) + dist(m,b)

2つの式は赤と青しか違わない。そして(★)より 赤 ≥ 青。だから:

dist(u,b) ≥ D ✅

3. Case 2: s→u の経路が直径に触れない場合

経路は m に着く前に、茎 s–m の途中の点 t で分岐して u へ逸れる。

dist(s,u) = dist(s,t) + dist(t,u)
dist(s,a) = dist(s,t) + dist(t,m) + dist(m,a)

「u は最遠」で緑が消えて:

dist(t,u) ≥ dist(t,m) + dist(m,a) … (★★)

u→b は 赤を戻って t → 橙で m → 紫で b:

dist(u,b) = dist(t,u) + dist(t,m) + dist(m,b)
　　　　 ≥ (dist(t,m) + dist(m,a)) + dist(t,m) + dist(m,b) 　(★★を代入)
　　　　 = D + 2·dist(t,m) ≥ D ✅

おまけ: D は最大なので dist(u,b) = D しかありえず、2·dist(t,m) = 0、つまり t = m。Case 2 は実は「c = m の Case 1」に潰れる。「直径に触れない遠回り」は存在できない、ということ。

4. 結論

どちらの場合も dist(u,b) ≥ D。D は全ペアの最大だから dist(u,b) = D。
つまり u は(b を相方とする)最遠ペアの端点であり、②で u から最遠距離を測れば必ず D が返る。

セクション0の頂点6が掴まれる心配は、こうして消えた: もし 6 が s から最遠なら、この証明により dist(6, b) = D でなければならない。実際には dist(6,·) の最大は 3 < 4 なので、6 は最遠点になれない。

タイの答えも同じ証明から出る。証明中、u に使ったのは「s から最遠である」ことだけ。だから最遠点が複数いても、どれを選んでもそれぞれが(何かを相方とする)直径の端点になっている。①のタイはどれを掴んでも安全。

手描きメモとの対応: 「外円になる」=「最遠点は葉」は補題として正しいが、それだけでは足りなかった。足りない分を埋めたのが(★)「枝の長さ ≥ 直径の残り」— 枝が最遠点を生むほど長いなら、その枝はもう直径の一部、という手描きの直感の不等式版。
