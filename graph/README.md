# グラフの勉強

binary_search と同じ流儀で進める:
「1問 = `src/bin/` 内の1ファイル」、`resolve()` + `#[cfg(test)]`、
naive対照(resolve1)とランダム突き合わせ、学びは `notes/*.md` に残す。

```sh
cargo test --bin <問題名>   # 1問だけテスト
cargo test                  # 全問一括テスト
```

## ロードマップ(問題は着手時に選定)

### Step 0: グラフの表現

- 隣接リスト(`Vec<Vec<usize>>`)の構築を手に馴染ませる
- 有向/無向、多重辺・自己ループの扱い

### Step 1: DFS(深さ優先探索)

- 連結判定、連結成分の数え上げ
- 再帰 vs 明示スタック(Rustの再帰深度の注意)

### Step 2: BFS(幅優先探索)

- 重みなしグラフの最短距離
- グリッド迷路(2次元をグラフとみなす)

### Step 3: Union-Find

- 自作する(二分探索と同じく、学習中は毎回手書き)
- 連結成分のマージ、クエリ処理

### Step 4: Dijkstra

- 重みつきグラフの最短路(BinaryHeap)

### Step 5: 木

- 木の性質(N頂点N-1辺、閉路なし)
- 木上のDP(educational-dp-contestとの合流点)

## メモ

- 頂点番号の0/1-indexed変換は入口で一度だけ(内部は0-indexedで統一)
- 訪問済み管理を忘れると無限ループ(二分探索の「区間が縮まない」に相当する定番事故)
